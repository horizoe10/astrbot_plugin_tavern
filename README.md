### 迁移说明

为了提供更稳定、更轻量的群聊跑团体验，我们将原本复杂的架构与世界引擎进行了彻底重构，推出了全新的 **321Roll Lite**。新版本具备以下改进：

- **轻量与稳定**：运行时零第三方依赖，兼容 Python 3.11+ 及 AstrBot 最新版本。
- **全新世界引擎**：内置六个预设世界，全面支持自定义世界可视化编辑与在线世界市场。
- **更优的群交互**：支持选项行动、自由描述检定、私聊建卡与查卡、卡片渲染出图及多平台消息适配。

### 如何迁移与安装

如果您正在使用旧版插件，建议先备份历史数据与自制世界包，然后在 AstrBot 中卸载旧插件，并选择以下方式安装新版：

1. **插件市场安装**：在 AstrBot 插件管理中输入新仓库地址：  
   `https://github.com/horizoe10/astrbot_plugin_321roll_lite`
2. **发布包安装**：前往新仓库的 Release 页面下载最新发布 zip 包上传安装。
