> 角色就位，世界开演。

321开团是基于 AstrBot 的多人跑团与世界运行插件。它围绕群聊副本提供私聊建卡、角色审核、回合选项、集体投票、AI 或真人主持、世界包、WebUI、存档和故障恢复。

## 能做什么

- 主持人可以创建多人副本、管理准备状态、暂停或恢复故事，并在 AI 主持与真人主持之间交接。
- 玩家通过私聊完成角色卡；候选项会说明用途、优势、限制和推荐理由，管理员可在群聊或 WebUI 审核。
- 故事推进包含行动选项、检定、投票和世界状态变化；失败时保留可恢复数据，不会提交半个回合。
- 世界包可以声明角色模板、场景、任务、NPC、阵营、时钟、结局和玩法说明，并通过作者工具预检与模拟。
- WebUI 提供世界库、跑团现场、角色管理、作者实验室、模型健康检查、备份与故障诊断。

## 安装和启用

1. 先备份现有插件数据和自制世界源码。
2. 在 AstrBot 插件管理中上传安装包，或把仓库放入 AstrBot 的插件目录。
3. 启用插件，在配置页填写管理员账号并选择故事模型；远程面板默认关闭，需要时再单独启用。
4. 重新加载插件，在群内发送：

   `/团 世界列表`

5. 确认能看到内置世界后再开团。若世界列表为空，先重新加载插件；仍失败时按故障排查文档检查世界安装状态。

## 管理员配置

至少完成以下配置：

- 管理员账号：用于开团、角色审核、主持控制和控制台管理。
- 故事模型：选择主要模型；需要时配置后备模型，并在 WebUI 执行主动健康检查。
- 允许的群聊：按 AstrBot 的插件启用范围开放目标群。
- 可选远程面板：启用时设置独立密码、访问范围和会话期限，不要直接暴露到公网。

完整配置项见[配置参考](docs/CONFIG_REFERENCE.md)。

## 从开团到开演

主持人在群内创建副本：

`/团 开启`

`/团 开启新副本 1` 或 `/团 开启旧副本 1`

玩家加入：

`/团 加入`

玩家收到私聊入口后开始建卡：

`/团 建卡 <验证码>`

建卡过程中可发送“当前步骤”“上一页”或候选的全局序号；需要重来时发送：

`/团 重新建卡`

完成后确认建卡，管理员审核角色卡；全员准备后由主持人开演：

`/团 开演`

详细步骤见[开团、建卡与角色管理](docs/USER_GUIDE.md)。

## 故事推进、投票和真人主持

回合中按机器人给出的字母选项行动：

`/团 选择 A`

需要集体决定时投票：

`/团 投票 A`

查看近期故事：

`/团 回顾`

真人主持可接管叙事、推进、直述或交回自动主持。具体命令和权限见[故事推进、投票与真人主持](docs/USER_GUIDE.md)。

## 暂停、取消、重试和恢复

暂停会先等待正在生成的故事安全停止，再冻结副本计时：

`/团 暂停`

取消当前尚未提交的故事生成：

`/团 取消`

保留已锁定的投票和检定并重试本轮：

`/团 重试本轮`

故障或暂停处理完成后恢复：

`/团 恢复`

取消建卡使用独立命令，避免和故事取消混淆：

`/团 取消建卡`

更多失败场景和系统自动处理见[恢复与常见错误](docs/USER_GUIDE.md)。

## 世界包、WebUI 与备份

- 世界包：管理员可从世界库安装、升级、归档或恢复；作者可使用随源码提供的工具预检和构建世界包。
- WebUI：从 AstrBot 插件页面进入控制台，按权限使用跑团现场、角色审核、作者实验室和健康检查。
- 备份：重要操作前创建备份；恢复前先停止正在推进的故事，并在 WebUI 核对备份状态。
