> 角色就位，世界开演。

321开团是一款基于 AstrBot 的多人文字跑团插件。它把开团、私聊建卡、角色审核、回合选择、集体投票、故事生成、AI 队友、世界包、WebUI 管理、存档和故障恢复串成一条完整流程，适合群聊长线战役，也适合快速短团。

当前版本：`v1.0.0-rc13`

## ✨ 一眼看懂

| 你想做什么 | 321开团可以提供 |
| --- | --- |
| 快速开一个多人团 | 创建副本、玩家加入、准备、开演和行动顺序 |
| 让玩家轻松建卡 | 私聊分步建卡、可读候选说明、角色卡审核与补充 |

| 管理长线战役 | 世界包、任务与时钟、记忆、存档、备份和恢复 |

## 📦 安装与启用

1. 先备份现有插件数据、自制世界和重要战役存档。
2. 在 AstrBot 插件管理中上传发布时提供的唯一安装 ZIP。安装包只有一个顶层 `astrbot_plugin_tavern/` 目录；不要把旧包、世界包或开发目录当作插件安装包。
3. 启用插件，在配置页填写管理员账号，并选择故事模型；需要时再配置后备模型。
4. 重新加载插件，在目标群发送：

   `/团 世界列表`

5. 确认能够看到世界后再创建副本。若世界列表为空，先重新加载插件；仍未恢复时查看[在线故障排查](https://github.com/horizoe10/astrbot_plugin_tavern/blob/main/docs/TROUBLESHOOTING.md)。

> 🔐 远程面板默认应保持关闭。确需启用时，请设置独立密码、访问范围和会话期限，不要直接暴露到公网。

## 🚀 从开团到开演

| 步骤 | 命令或操作 | 说明 |
| --- | --- | --- |
| 1. 创建副本 | `/团 开启 <副本>` | 由管理员或主持人发起 |
| 2. 加入副本 | `/团 加入` | 玩家在群内加入 |
| 3. 私聊建卡 | `/团 建卡 <验证码>` | 按候选全局序号或完整名称回复 |
| 4. 审核与准备 | WebUI 或群内流程 | 管理员审核角色卡，玩家完成准备 |
| 5. 正式开演 | `/团 开演` | 全员准备后开始故事 |

建卡需要重来时使用 `/团 重新建卡`；取消建卡使用 `/团 取消建卡`。字段太多写不动时，可以在建卡私聊中使用 AI 设定助手：`/团 随机`（别名 `sj`）让模型直接为当前字段生成一份设定，`/团 补全 <初始设定>`（别名 `bq`）在保留你的创意的前提下扩写补全，例如 `/团 补全 一个腐朽的木制魔杖和一本老旧的魔法书`。生成内容仍走原有字段校验；不满意可 `/团 上一步` 后重新生成。完整流程见仓库中的[使用指南](https://github.com/horizoe10/astrbot_plugin_tavern/blob/main/docs/USER_GUIDE.md)。

## 🎭 故事推进与正文模式

按机器人给出的选项行动：

`/团 选择 A`

需要全队决定时投票：

`/团 投票 A`

活动挑战中可以发送 `/团 挑战` 查看目标、风险和失败推进；发送 `/团 挑战行动 <说明>`、`/团 退出挑战 <出口或保护对象>` 或 `/团 挑战谈判 <提案与担保>` 建立草稿，再用 `/团 确认挑战` 提交。主持人或管理员用 `/团 开始挑战 <序号>` 从冻结世界选择模板，并用 `/团 推进挑战`、`/团 结束挑战 <结果> <依据>` 控制阶段和结算。

战术冲突使用 `/团 战况` 查看当前轮次、区域、威胁和行动额度。玩家可发送 `/团 行动 <目标或说明>`、`/团 防守 <对象>`、`/团 援助 <对象>`、`/团 撤退 <出口>` 或 `/团 谈判 <提案>` 建立草稿，再用 `/团 确认行动` 提交或直接重新发送说明替换自己的草稿。主持人或管理员用 `/团 开始战术 <序号> [议政|均衡|冒险]` 选择冻结模板，随后用 `/团 推进战术` 进入声明阶段、`/团 锁定行动` 冻结本轮声明，并继续推进玩家、敌方、环境和轮末结算；纠错与结束分别使用 `/团 纠正战术 <说明>`、`/团 结束战术 <结果> <依据>`。

挑战与战术不会从聊天文本猜规则。服务端会校验参与者、目标、区域、公开目标、能力、装备、资源和当前阶段；能力成本、装备耐久或充能、元素暴露、环境危机、时钟和终局效果按冻结合同结算。主状态和关联效果使用同一事务与版本比较更新，任何一项冲突都会整体回滚。若响应丢失，相同请求会先查询持久回执，不会重复掷骰、扣资源或应用效果。

主持人或管理员可以在 WebUI 的“跑团现场”调整正文模式：

| 模式 | 目标长度 | 适合场景 |
| --- | ---: | --- |
| 极简 | 350—600 字 | 快节奏推进，省略次要细节 |
| 平衡 | 700—1200 字 | 日常回合，兼顾节奏与氛围 |
| 史诗 | 1400—2600 字 | 关键场景、高潮和强沉浸叙事 |

故事会在合适的场景加入分行对白，并用神态、动作、视线、停顿和语气补足沉浸感；较长内容会按安全段落拆分投递。更多玩法见仓库中的[使用指南](https://github.com/horizoe10/astrbot_plugin_tavern/blob/main/docs/USER_GUIDE.md)。

正文模式之外还有独立的“叙事文风”轴：多对白、偏对白、均衡、偏描写、多描写。它只调整下一回合对白与细节的侧重，不改变规则、事实、权限、安全边界或玩家决定；主持人可在跑团现场打开“详细文风”设置当前副本的受限期望。

当前安装包只内置《第十三席：万邦新纪》。它保留七幕因果，并加入 8 个冒险站点、8 个新增任务、28 个挑战、28 个战术冲突、24 件远征装备、20 个配方、动态危机、三档冒险强度和八元素环境。其他世界可作为单独受检的 TWP 世界包导入。世界 ZIP 根目录包含离线可读 `README.md`；WebUI 的世界设定阅读面按角色和章节安全投影，不把完整手册逐回合发送给模型。

## ❤️ 角色命运与救援

致命命运不会由普通挑战、战术结果或模型文本直接写入。系统会先生成只属于目标角色本人的预览，列出危险来源、致命原因、替代方案和有效期。主持人和管理员可以组织场景与救援，但不能代替角色本人确认或拒绝。

| 操作 | 命令 | 结果 |
| --- | --- | --- |
| 查看本人待确认预览 | `/团 命运预览` | 只显示当前账号自己的预览，不读取他人内容 |
| 确认进入救援 | `/团 命运确认 <编号>` | 进入世界声明的非终态救援窗口，不会直接判定死亡 |
| 拒绝本次致命命运 | `/团 命运拒绝 <编号>` | 保留当前命运状态，不开启本次救援窗口 |
| 执行救援 | `/团 救援 <角色完整名称或副本昵称>` | 当前副本中已完成建卡的出场角色可在开放窗口内施救 |

预览过期、版本冲突、窗口关闭或同一请求已经处理时，系统会保留现状并给出刷新或查看原回执的下一步，不会用新请求覆盖已经确定的命运结果。

## 🛟 暂停、重试与恢复

| 情况 | 命令 | 系统行为 |
| --- | --- | --- |
| 暂停当前副本 | `/团 暂停` | 等待正在生成的内容安全停止，再冻结推进 |
| 取消未提交生成 | `/团 取消` | 保留已经确定的故事事实，不重复结算 |
| 重试本轮 | `/团 重试本轮` | 从可恢复位置继续生成或投递 |
| 恢复副本 | `/团 恢复` | 完成安全检查后继续故事 |
| 查看近期故事 | `/团 回顾` | 阅读最近的故事与结果 |

更多错误原因、自动处理和下一步命令见仓库中的[使用指南](https://github.com/horizoe10/astrbot_plugin_tavern/blob/main/docs/USER_GUIDE.md)。

## 🖥️ WebUI 与世界包

- 从 AstrBot 插件页面进入 WebUI；不同身份只会看到自己有权使用的页面和操作。
- “跑团现场”用于观察故事、小队、AI 队友、挑战、战术、本人命运预览、世界状态与回放；其他页面用于角色审核、世界创作、投递审计、设置和健康检查。
- 短时连接中断后，页面会携带最后收到的顺序号补读持久事件并去重；游标过旧、无效或出现缺口时会明确刷新受影响页面，不会把整段历史伪装成连续实时流。
- 世界库支持内置世界和受检世界包；进行中的副本使用创建时冻结的世界内容，不会被后来更新静默改写。
- 重要操作前请创建备份；恢复前先停止正在推进的故事，并核对快照或备份状态。

## 🌐 公网访问网页建卡

网页建卡、网页审核等功能需要从浏览器访问独立面板（默认端口 8766），有两种方式：

**方式一：有域名（推荐）**

用 Nginx / Caddy 等做 HTTPS 反向代理到 8766，然后把插件配置 `remote_panel.public_url` 填为你的域名地址（如 `https://www.example.com`）。此时无需开启 `allow_insecure_http`，传输全程加密。

**方式二：无域名，直连服务器 IP**

没有域名也能用，共三步：

1. 插件配置 `remote_panel.host` 改为 `0.0.0.0`（默认 `127.0.0.1` 仅本机可访问）；
2. 在云服务器安全组/防火墙放行 8766 端口（Docker 部署还需给容器加 `-p 8766:8766` 端口映射）；
3. 开启 `remote_panel.allow_insecure_http`——这是关键开关：不开启时，插件会**主动拒绝**所有非本机的明文 HTTP 访问，即使端口开了也进不来。

`public_url` 可填 `http://服务器IP:8766`，机器人下发的建卡/审核链接就会带上这个地址。

**⚠️ 直连 IP 的风险须知**：明文 HTTP 意味着登录密码和链接令牌在网络中不加密传输，且 8766 直接暴露公网、没有反向代理层的限流保护。开启前请务必修改默认管理员密码（admin/admin），并只在自己和团友的小圈子内使用。
