# v0.12.0 安装与升级说明

## 新安装

在 AstrBot 插件管理器上传 `astrbot_plugin_tavern-v0.12.0.zip`，或解压完整源码到插件目录。重启 AstrBot 后确认日志出现 v0.12.0、Schema 12 和 Web 控制器启动信息。配置至少一个真实管理员 ID，再从目标群发送 `/酒馆 开启`。

## 从旧版升级

1. 停止正在进行的写操作，保存当前副本快照。
2. 备份整个插件数据目录、数据库文件、自定义世界包和自定义 NPC 包。
3. 安装 v0.12.0 覆盖插件代码，不要手工覆盖数据目录。
4. 重启插件。迁移器会检测旧 Schema，先创建时间戳备份，再逐级迁移至 Schema 12。
5. 登录 WebUI，检查“关于插件”的版本与 Schema；再检查副本、角色、世界、待办通知和审计日志。
6. 对每个重要旧副本执行一次只读检查，确认回合行动者、活动选项、投票、计时器和世界状态。

## 兼容行为

- 旧世界包 v2–v4 可继续导入；不会强制写回源文件。
- 旧副本保持冻结世界快照，世界库中的新版本不会热替换运行中副本。
- 旧建卡提醒会补齐 v0.12.0 字段并延后到下一提醒周期，不会在升级瞬间刷屏。
- 旧角色草稿中的非身份字段允许保留历史空白字符；姓名和代号仍执行严格 12 字符与空白限制。
- QQ REST 与富卡片配置不再读取或执行。升级不会删除业务数据，但相关设置不再出现在 WebUI。

## 回退

v0.12.0 数据库迁移不可由旧插件直接安全读取。需要回退时，停止 AstrBot，恢复升级前的整个数据目录或迁移备份，再恢复旧插件代码。不要把 Schema 12 数据库交给旧版本继续写入。

## 验收

确认 `/酒馆 开启`、加入、私聊建卡、准备、开演、选择、投票、检定、暂停/继续均正常；WebUI 登录后页面无 404/500，待办通知可重试；世界体检可识别 v2–v5；日志没有重复迁移或重复通知。
