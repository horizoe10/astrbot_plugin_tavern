# v0.12.0 新增功能使用说明

## 全平台文本投递

所有输出统一为纯文本。普通群回复由当前事件发送；主动通知通过 AstrBot 平台实例发送。失败通知会显示在 WebUI“待办”，管理员可重试或忽略。`next_event` 队列会在目标用户下一次事件到达时自动补发；同一去重键不会重复入队。

## 多人体验策略

在“世界包管理 → 编辑世界 → 多人群聊体验”配置建卡通道、聚光灯、集体决策、缺席策略、安全边界、连续性和投递回退。配置属于世界，创建副本时冻结，适合不同世界采用不同节奏。

## 人工 DM

先以管理员或 DM 权限进入目标副本，再打开人工 DM 控制台。可执行叙事、公告、秘密耳语、手工检定和受控状态操作。世界关闭的能力会被禁用并显示原因；接口直接调用同样会被后端拒绝。危险操作必须提供目标、原因和可审计信息。

## 通知发件箱

发件箱保存目标平台、会话、用户、文本、种类、去重键、尝试次数、最后错误和状态。成功后标记发送；失败可重试；管理员忽略只改变通知状态，不删除业务事件。它用于通知补偿，不替代剧情事件日志。

## 自动连续性

世界包可指定每若干回合生成回顾与检查点。检查点间隔直接驱动自动快照；未决线索和 NPC 意图进入受预算限制的叙事上下文。建卡预设、作者说明和重复世界定义不再反复塞入每次模型请求。

## 计时器恢复

倒计时按副本总开关和分类开关共同决定。启用已有暂停计时器时会恢复剩余时间并补齐默认提醒间隔；周期提醒会安排下一周期；关闭策略会冻结而不是偷偷过期。旧建卡提醒首次轮询时进行无刷屏迁移。
