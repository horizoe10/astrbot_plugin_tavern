# v0.12.0 平台适配指南

v0.12.0 只使用 AstrBot 统一文本消息能力，不再包含 QQ REST API 或富卡片实现。核心指令、回合、检定、投票与建卡逻辑不区分平台；差异集中在命令路由、私聊事件和主动消息能力。

## 能力模型

- 当前群事件回复：使用 AstrBot 事件原生文本回复。
- 主动群消息或私聊：通过事件的统一消息来源及 AstrBot 平台实例发送。
- 文本长度：先应用世界包上限，再应用平台能力上限，按自然段和安全边界分段。
- 失败：记录适配器错误并执行 `next_event`、`webui_only` 或 `discard`，不返回虚假成功。
- 未知第三方适配器：按通用主动文本能力尝试；实际失败后进入同一补偿流程。

## 已声明平台

`metadata.yaml` 列出 aiocqhttp、QQ 官方、Telegram、企业微信、飞书、钉钉、Discord、Slack、KOOK、VoceChat、微信公众号、Satori、Misskey、LINE、Matrix、微信、Mattermost 与 WebChat。该清单表示插件不会主动拒绝这些平台，不代表每个适配器都提供相同的主动私聊权限。

## 命令与 ID

不同平台可能吞掉 `/` 或使用不同命令前缀；玩家可使用 `jg A` 作为选择短命令。管理员 ID、群 ID、OpenID、雪花 ID 等必须填写适配器实际暴露的字符串，不能跨平台复用猜测值。

## 私聊建卡

推荐 `private_code`：玩家从群内取得一次性码，在私聊中绑定。私聊事件不带群上下文时仍可通过码定位副本。平台不支持私聊时，世界作者可在 `character_creation.fallbacks` 配置 `webui_token`。

## 排查

| 现象 | 排查点 |
|---|---|
| 指令没反应 | 适配器前缀、群白名单、管理员 ID、是否使用 `jg` 短命令 |
| 主动通知失败 | WebUI 待办的目标平台、实例 ID、最后错误与尝试次数 |
| 私聊无法建卡 | 私聊事件是否到达 AstrBot、建卡码是否过期、是否配置 WebUI 备用 |
| 文本被截断 | 世界 `delivery.max_text_length` 与平台分段能力 |
| 通知重复 | 检查去重键、事件重放和是否存在多个插件实例同时消费同一数据目录 |
