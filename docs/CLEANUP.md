# v0.12.0 “做减法”与历史清理说明

## 已删除或停用

- QQ REST API 发送器、QQ 专属富卡片运行分支、富消息配置与 WebUI 入口。
- 37 份已被后续版本取代的 A/Alpha 版本说明、实施规划、旧架构快照和重复交付清单。
- Python/pytest 缓存、编译产物和打包临时文件不进入安装包。

删除前已全仓检索文件名和接口引用；这些历史文档不参与数据库迁移、旧存档、旧世界包或运行时加载。旧业务数据没有因清理被删除。

## 已合并

- 平台发送统一到文本能力矩阵和可靠投递入口。
- 副本中的关系、背包、经济、NPC 和日志使用单一后端数据源，不新增第二套维护逻辑。
- 人工 DM 的页面可用性与后端权限统一由世界策略决定。
- 新世界模板统一到模板包 4.0.0；旧协议通过兼容层读取，不保留多套运行实现。

## 保留

当前架构、配置参考、平台指南、排障、升级与存档、世界创作、最佳实践以及 v2/v3/v5 协议资料继续保留，因为它们仍服务旧包兼容或当前作者工作流。

## 风险控制

没有删除旧数据库表、迁移代码、世界协议解析器、ID 别名工具、快照格式或旧角色草稿兼容逻辑。所有历史清理只针对无引用文档、缓存和已被文本投递替代的代码入口。
