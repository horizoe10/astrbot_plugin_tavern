# v0.12.0 WebUI 操作说明

## 页面结构

- 概览：服务状态、当前副本、关键指标和常用操作。
- 副本：SESSION INSPECTOR、LIVE OPERATIONS、实时仪表盘、角色与托管、人工 DM、受控世界状态、选项/投票、关系、背包、经济、NPC、时间线和恢复操作。
- 待办：待发送通知、异常提示、重试与忽略。
- 世界包：导入、体检、编辑、克隆、归档、NPC 与多人体验策略。
- 世界市场：内置/模板/远程清单浏览；远程读取需 AstrBot 宿主允许网络访问。
- 记忆与日志：剧情记忆、审计、错误和诊断。
- 设置与关于：控制器配置、权限说明、版本、Schema 与平台能力。

## 操作反馈

按钮执行后会显示加载、成功或失败状态；空列表显示下一步建议；危险操作要求确认。输入框包含用途提示，权限不足或世界策略关闭时控件会禁用并说明原因。待办重试只在实际送达后显示成功。

## 人工 DM

选择副本后进入人工 DM 区。叙事覆盖面向全群；秘密耳语必须选择单个目标；手工检定必须填写检定属性、DC、风险和理由；状态干预属于高级危险操作。所有权限由后端校验并写入审计日志。

## 世界编辑

普通信息和多人体验放在主要区域；协议、调试和危险配置折叠。保存时先体检，再写入新修订。运行中副本不会自动切换到新修订，需要新建、克隆或按迁移流程处理。

## 视觉与响应式

v0.12.0 统一 14–16px 卡片圆角、精细边框、柔和阴影、20px 常规内边距、统一标题层级和状态色。页面与主模块采用轻微淡入/位移动画，弹窗和折叠使用同一节奏。窄屏自动单列并收敛操作区；系统开启“减少动态效果”后禁用非必要动画。

## 故障处理

页面加载失败时先看可见错误与连接状态，再检查 AstrBot 日志。登录跳转循环通常来自 Token、反向代理路径或 Cookie；实时刷新失败不会清空当前数据。操作按钮无响应应记录为缺陷，不应反复点击危险操作。
