# 排障手册（Troubleshooting）

> 结合诊断报告（`sessions/diagnostics`）与日志使用。诊断报告已脱敏：用户 ID 哈希、密钥/密码/系统提示词移除、超长字段截断。

## 一、如何获取诊断信息

1. 控制台 → 群会话 → 目标副本 → 「诊断」导出脱敏诊断报告；
2. 打开调试日志（配置 `advanced.debug = true`）后复现问题；
3. 需要保留原始模型载荷时开启 `advanced.store_model_payloads`（会增大数据库，排查后请关闭）。

## 二、常见故障

### 1. 指令没反应 / 文本未送达

- **现象**：`/酒馆 xxx` 无响应，或主动通知没有到达。
- **原因**：
  - QQ 官方接口吞 `/`（`all_as_at` 时序）；已内置 `_parse_command_relaxed` 兜底，但若适配器前缀配置冲突仍会失效；
  - 平台不支持主动私聊、目标平台实例已经下线，或统一消息来源失效；
  - 群不在白名单、发送者非管理员。
- **处理**：核对平台适配器命令前缀 → 核对 `admin_ids` / `allowed_group_ids` → 在 WebUI 待办查看最后错误并重试。

### 2. 主动消息被拒（频控 40034100）

- **原因**：QQ 官方接口对主动消息有频控；同一轮过多提醒会被整段拒绝并重试刷屏。
- **处理**：插件已内置「计时器单循环 + 去重 + 失败退避」；仍可降低 `time_rules` 中各类提醒频率，或关闭 `announce_timeouts`。

### 3. 投票结束后不推进

- **原因**：定时器驱动的投票结束可能不携带「表决通过 → 推进叙事」的触发（历史缺陷，v0.11.3 已修复为按实票判定并标记 `pending_resolution`）。
- **处理**：升级到 v0.11.3+；仍不推进时发送任意一条剧情消息触发 `pending_resolution` 自动续写。

### 4. 检定骰面与叙事不一致

- **原因**：表决路径曾丢弃 `lock_check_result` 返回值，模型失败重试会用新骰面（v0.12.0 已修复为复用凭证骰面）。
- **处理**：升级到 v0.12.0；回放与展示应始终一致。

### 5. Windows 下临时目录 / 备份清理失败（WinError 32）

- **原因**：SQLite 连接在操作结束后短暂滞留会锁住文件。插件刻意采用「每操作新建连接、退出即关闭」，这是承重设计（v0.12.0 曾评估连接池后因该原因回退）。
- **处理**：重试清理；不要在插件运行中直接删除 `data_dir`；备份用控制台「备份导出」。

### 6. 建卡码过期 / 无法绑定

- **原因**：默认 1800 秒过期；跨设备绑定依赖平台消息 ID 稳定。
- **处理**：调整 `time_rules.card_code_ttl_seconds`；过期会自动补发（`-1` 表示不限时，v0.11.1 已修复不限时建卡码不被误标过期）。

### 7. 世界包导入冲突（409）

- **原因**：同 slug 已存在且内容版本相同，但内容不同。
- **处理**：控制台弹窗三选一（覆盖为新修订 / 另存副本 / 取消）；`worlds/migration` 可先对比冻结契约差异。

## 三、日志关键标记

| 标记 | 含义 |
|---|---|
| `notification_outbox` / 投递失败 | 主动文本已进入可靠通知补偿流程 |
| `AI 酒馆 <stage>.<op> 失败（transient/integrity/policy/unknown）` | v0.12.0 统一失败上报（`tavern/errors.py`） |
| `AI 酒馆计时器轮询异常，将在稍后重试` | 定时器循环自愈 |

## 四、数据库维护

- 数据库：`data_dir/catalog_v090.sqlite3`（Schema 10），WAL 模式；
- 自动备份：迁移前自动生成 `catalog_v090.schema{旧}.before_schema{新}.*.sqlite3`；
- 完整备份：控制台「备份导出」（ZIP，含数据库与独立存档目录）。
